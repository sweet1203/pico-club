4차시

심장 박동

회로는 지난 시간 그대로입니다. 켜고 끄는 시간만 바꿔 두근, 두근, 쉼이 되게 합니다.

  1. 시간으로 패턴 만들기
  2. 두근두근
  3. 숫자 바꿔 보기
01

원리

원리피코는 심장 소리를 알지 못합니다. 켜진 시간과 꺼진 시간을 우리가 정하면 보는 사람에게는 패턴이 됩니다. 짧은 불 두 번과 긴 쉼입니다. LED는 그대로 GP14, 저항 220Ω, GND입니다.
다른 교재의 심장은 가변 저항으로 빠르기를 바꿉니다. 그 부품은 키트에 없어서, 우리는 코드의 숫자만 바꿉니다.
02

두근두근

heartbeat.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)

while True:
    led.on()
    time.sleep(0.12)
    led.off()
    time.sleep(0.12)
    led.on()
    time.sleep(0.12)
    led.off()
    time.sleep(0.6)
  • 위쪽 두 번의 on이 두근두근이고, 마지막 0.6이 쉼입니다.
  • 0.6을 0.3으로 줄이면 빨라지고, 1.0으로 늘이면 느려집니다.
  • 종이 하트를 LED 위에 얹어도 됩니다. 부품은 더 필요 없습니다.
