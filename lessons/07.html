버튼 벨

버튼을 누르는 동안 부저가 울리게 합니다. 음계는 다루지 않고, 켜고 끄는 소리만 만듭니다.

원리 부저도 출력입니다. 핀을 켜면 소리가 나고 끄면 그칩니다. 키트 부저는 이 방식(능동 부저)으로 울리게 연결되어 있는 경우가 많습니다. 도레미처럼 음 높이를 바꾸려면 수동 부저와 다른 신호가 필요해서, 오늘은 「삑」만 합니다.
자리는 GP13 정보 수업에서는 버튼을 뺀 자리에 부저를 꽂기도 합니다. 이 동아리에서는 버튼이 GP15를 계속 쓰므로 부저는 GP13, 보드 핀 17입니다. 15번에 부저를 꽂으면 버튼과 자리가 겹칩니다.

연결

USB를 뽑고 부저만 더합니다. LED와 버튼은 그대로 둡니다.

부저연결
+ 또는 긴 다리, 빨간 선GP13, 보드 핀 17
− 또는 짧은 다리, 검은 선가까운 GND. 왼쪽 GND인 핀 13, 또는 오른쪽 GND인 핀 23

실습 · 누르는 동안 삑

button_bell.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)
buzzer = Pin(13, Pin.OUT)

while True:
    if button.value() == 1:
        buzzer.on()
        led.on()
    else:
        buzzer.off()
        led.off()
    time.sleep(0.05)

바꿔 보기 · 세 번만 울리는 초인종

누르는 순간 짧게 세 번만 울리고, 손을 뗄 때까지 더 울리지 않습니다.

doorbell.py
from machine import Pin
import time

button = Pin(15, Pin.IN, Pin.PULL_DOWN)
buzzer = Pin(13, Pin.OUT)
before = 0

while True:
    now = button.value()
    if now == 1 and before == 0:
        for _ in range(3):
            buzzer.on()
            time.sleep(0.08)
            buzzer.off()
            time.sleep(0.12)
        while button.value() == 1:
            time.sleep(0.01)
    before = button.value()
    time.sleep(0.05)

막히면

  • 소리가 전혀 없음 → +와 −를 바꿔 꽂아 봅니다. 능동 부저는 방향이 있습니다. 코드 숫자가 13인지도 봅니다.
  • 딸깍 소리만 남 → 수동 부저일 수 있습니다. 오늘 목표인 「눌렀다」는 신호로는 쓸 수 있고, 노래를 만들지는 않습니다.
  • 버튼이 안 먹고 부저만 이상함 → 부저 선이 GP15나 3V3에 닿지 않았는지 봅니다.

이 동아리에서 부저 +를 꽂는 핀은?

버튼이 GP15를 쓰고 있으므로 부저는 GP13입니다. 5V에 부저를 직접 잇지 않습니다.
