심장 박동

회로는 지난 시간 그대로입니다. 켜고 끄는 시간만 바꿔 두근, 두근, 쉼이 되게 합니다.

원리 피코는 심장 소리를 알지 못합니다. 켜진 시간과 꺼진 시간을 우리가 정하면, 보는 사람에게는 패턴이 됩니다. 심장 박동은 짧은 불 두 번과 그 뒤의 긴 쉼입니다.

연결

3차시 회로를 그대로 둡니다. LED는 GP14, 짧은 다리는 GND, 사이에는 220Ω입니다.

실습 · 두근두근

heartbeat.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)

while True:
    led.on()
    time.sleep(0.12)
    led.off()
    time.sleep(0.12)
    led.on()
    time.sleep(0.12)
    led.off()
    time.sleep(0.6)

위쪽 두 번의 on 이 두근두근이고, 마지막 0.6 이 다음 박동까지의 쉼입니다.

바꿔 보기

  • 쉼 0.6 을 0.3 으로 줄이면 박동이 빨라집니다. 1.0 으로 늘이면 느려집니다.
  • 두 번째 쉼 0.12 만 0.25 로 늘이면, 첫 박과 둘째 박 사이가 벌어집니다.
  • 종이로 작은 하트를 접어 LED 위에 얹으면 빛이 퍼집니다. 부품은 더 필요 없습니다.
다이얼은 키트에 없음 다른 교재의 심장 예제는 가변 저항으로 빠르기를 바꿉니다. 우리는 코드의 숫자로만 바꿉니다. 숫자를 바꾼 뒤 정지하고 다시 실행합니다.

패턴을 하나 더

모스 부호의 SOS는 짧게 세 번, 길게 세 번, 짧게 세 번입니다. 짧은 켜짐 0.15초, 긴 켜짐 0.45초로 정해 보고, 글자 사이에 쉼을 넣습니다. 정답이 하나만 있는 활동이 아니니 옆 사람과 패턴이 달라도 됩니다.

박동을 더 느리게 하려면 어디를 바릅니까?

쉼이 길수록 다음 두근까지 늦어집니다. 핀을 바꾸면 다른 불이 켜지거나 안 켜집니다.
