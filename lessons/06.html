6차시

반응 속도 대결

회로는 버튼과 LED 그대로입니다. 불이 켜지면 버튼을 누르고, 몇 밀리초가 걸렸는지 셸에서 겨룹니다.

원리 time.ticks_ms() 는 피코가 켜진 뒤 흐른 시간을 밀리초로 알려 줍니다. 불이 켜진 시각과 버튼을 누른 시각의 차이가 반응 시간입니다. 기다리는 시간을 매번 같게 하면 박자에 맞춰 미리 누를 수 있어서, random.randint 로 1.5초에서 4초 사이를 뽑습니다.

연결

5차시와 같습니다. LED는 GP14, 버튼은 GP15와 3V3(핀 36)입니다. 새 부품은 없습니다.

노는 법

  1. 실행하면 셸에 시작 안내가 나옵니다.
  2. 버튼을 짧게 눌렀다 뗍니다. 그게 한 판의 시작입니다.
  3. 불은 꺼져 있습니다. 켜지기 전에 누르면 “너무 일렀어요”가 나오고 그 판은 무효입니다.
  4. 불이 켜지면 바로 누릅니다. 기록 240 ms 같은 글자가 나옵니다. 숫자가 작을수록 빠릅니다.
  5. 다섯 판이 끝나면 최고 기록이 나옵니다. 정지 버튼을 누르고, 옆 사람과 자리를 바꿉니다.
reaction.py
from machine import Pin
import time
import random

led = Pin(14, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)

def wait_release():
    while button.value() == 1:
        time.sleep(0.01)

print("버튼을 짧게 누르면 시작. 불이 켜지면 다시 누르세요.")
best = None

for n in range(1, 6):
    print(n, "번째")
    while button.value() == 0:
        time.sleep(0.01)
    wait_release()

    led.off()
    wait_ms = random.randint(1500, 4000)
    early = False
    t0 = time.ticks_ms()
    while time.ticks_diff(time.ticks_ms(), t0) < wait_ms:
        if button.value() == 1:
            early = True
            break
        time.sleep(0.01)

    if early:
        print("너무 일렀어요")
        for _ in range(3):
            led.on()
            time.sleep(0.08)
            led.off()
            time.sleep(0.08)
        wait_release()
        continue

    led.on()
    start = time.ticks_ms()
    while button.value() == 0:
        time.sleep(0.001)
    ms = time.ticks_diff(time.ticks_ms(), start)
    led.off()
    wait_release()
    print("기록", ms, "ms")
    if best is None or ms < best:
        best = ms
        print("오늘 최고")

if best is None:
    print("끝. 성공한 기록이 없어요")
else:
    print("끝. 최고 기록", best, "ms")
led.off()

다섯 판이 모두 너무 이른 출발이면 성공한 기록이 없다고 나옵니다. 코드를 고친 뒤에는 정지하고 다시 실행합니다.

막히면

  • 시작하자마자 바로 “너무 일렀어요” → 버튼을 누른 채 손을 안 뗀 것입니다. 뗐다가 다시 시작합니다. 그래도 그러면 버튼이 항상 1입니다. 5차시 막히면 항목을 봅니다.
  • 기록이 10ms보다 작게 계속 나옴 → 불이 켜지기 전에 이미 눌린 상태로 읽힌 것입니다. 버튼을 완전히 떼고 다시 합니다.
  • 사람마다 보통 180~350ms 근처에 있습니다. 50ms 아래가 반복되면 회로를 의심합니다.

기다리는 시간을 매번 바꾸는 이유는?
