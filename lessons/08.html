8차시

지나가면 켜지고, 지나가면 삑

버튼을 빼고 인체 감지 센서를 넣습니다. 움직임이 있으면 LED가 켜지고, 막히면 부저는 그 순간 한 번만 울립니다.

원리 이 센서는 사람 몸에서 나오는 적외선이 변할 때 1을 보냅니다. 움직임 센서라서, 앞에 가만히 서 있으면 잠시 뒤 0으로 돌아옵니다. 버튼과 같이 값은 0 또는 1이고, 핀 번호만 다릅니다. 기판의 작은 다이얼 두 개 중 하나가 감도, 하나가 켜져 있는 시간(약 0.3초~5분)입니다.

연결

USB를 뽑습니다. 버튼과 버튼의 3V3 선을 먼저 뺍니다. LED와 부저는 남겨 둡니다. 센서 핀은 기판에 적힌 글자 기준입니다. 그림의 줄 순서가 아니라 VCC, OUT, GND를 읽습니다.

센서 글자피코
VCCVBUS, 보드 핀 40. 이 센서는 5V로 동작하는 형이 많습니다.
OUTGP28, 보드 핀 34
GND아무 GND. 오른쪽 위쪽 GND인 핀 38이 가깝습니다.
5V는 센서 VCC에만 핀 40 선이 GP 핀이나 부저, LED에 닿으면 안 됩니다. 센서는 수 핀이라 암-수 점퍼로 브레드보드에 연결합니다.

실습 1 · 지나가면 켜지는 불

실행 뒤 1분 정도 센서가 안정될 수 있습니다. 종이컵으로 센서를 덮고 컵 안에 손만 넣었다 빼 봅니다. 옆 사람의 움직임에 반응하지 않게 하려는 것입니다.

pir_light.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
pir = Pin(28, Pin.IN, Pin.PULL_DOWN)

while True:
    if pir.value() == 1:
        led.on()
    else:
        led.off()
    time.sleep(0.1)

손을 뺀 뒤에도 불이 잠시 켜져 있으면, 그게 감지 유지 시간입니다. 너무 길면 다이얼을 가장 짧게 돌립니다. 수업 전에 짧게 맞춰 두면 좋습니다. 불이 꺼진 직후 몇 초는 다시 반응하지 않을 수 있습니다.

실습 2 · 처음 감지될 때 한 번만 삑

사람이 계속 있어도 부저가 계속 울리면 교실이 시끄럽습니다. 0에서 1로 바뀌는 순간만 0.1초 울립니다.

pir_beep.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
buzzer = Pin(13, Pin.OUT)
pir = Pin(28, Pin.IN, Pin.PULL_DOWN)
before = 0

while True:
    now = pir.value()
    if now == 1 and before == 0:
        buzzer.on()
        time.sleep(0.1)
        buzzer.off()
    if now == 1:
        led.on()
    else:
        led.off()
    before = now
    time.sleep(0.05)

오늘 안에 바꿔 보기

  • 컵을 씌우기 전과 후의 오작동이 어떻게 다른지 한 문장으로 적습니다.
  • 유지 시간을 짧게, 그다음 조금 길게 돌려 보고 꺼지는 시간을 셉니다. 돌린 뒤에는 손을 치우고 기다립니다.
  • 시간이 남으면 부저 없이 LED만, 또는 LED 없이 부저만 남겨 어느 쪽이 더 알아채기 쉬운지 말해 봅니다.

막히면

  • 전원 직후 혼자 켜졌다 꺼짐 → 안정될 때까지 1분 정도 기다립니다.
  • 한 번 켜지면 몇 분째 안 꺼짐 → 유지 시간 다이얼이 최장입니다. 최소로 돌립니다.
  • 아무도 없는데 켜짐 → 복도나 옆 사람을 보고 있습니다. 종이컵으로 덮습니다.
  • LED만 안 켜짐 → GP14 회로가 3차시 그대로인지 봅니다. 센서와 LED는 핀이 다릅니다.

센서 OUT은 어디에 연결합니까?

신호는 GP28입니다. GP14는 LED, 핀 37은 전원 끄기용이라 비워 둡니다. VCC만 핀 40입니다.

앞에 사람이 가만히 있으면 어떻게 되는 센서입니까?

적외선의 변화를 보므로 정지하면 꺼집니다. 피코 H에는 와이파이가 없습니다.

여덟 시간을 한 줄로 피코 H는 핀으로 0과 1을 읽고 내보냅니다. LED와 부저는 출력, 버튼과 인체 감지 센서는 입력입니다. 시간 간격이 패턴이 되고, 0에서 1로 바뀌는 순간만 잡으면 한 번만 울리는 벨이 됩니다.
