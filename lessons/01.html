피코는 어떤 보드일까

오늘은 코드를 쓰지 않습니다. 이름을 구분하고, 우리 보드에서 USB 구멍, 초록 불, BOOTSEL 버튼을 손가락으로 찾습니다.

한 줄로 라즈베리파이는 화면이 있는 작은 컴퓨터이고, 피코는 불·버튼·센서처럼 한 가지 일을 반복하는 작은 제어 보드입니다. 우리 키트는 그 피코 중에서도 피코 H입니다.

이름이 여럿인 이유

이름무엇인가우리 키트

그래서 인터넷 예제를 붙이기 전에 제목에 Pico W, Pico 2, Grove, NeoPixel, Wi-Fi가 있으면 우리 수업 코드가 아닙니다. 이 코스웨어 코드를 씁니다.

피코가 하는 일

입력

바깥 신호를 읽습니다. 버튼이 눌렸는지, 사람이 지나갔는지를 0 또는 1로 받습니다.

출력

핀으로 전기를 내보냅니다. LED를 켜고, 부저를 울립니다. 켜짐이 1, 꺼짐이 0입니다.

가운데서 판단하는 프로그램이 마이크로파이썬입니다. 다음 시간에 컴퓨터의 Thonny에서 그 프로그램을 피코로 보냅니다.

보드에서 찾기

  1. 은색 USB 구멍이 있는 쪽이 위입니다. 컴퓨터와 연결하는 곳이고, 피코 H는 마이크로 USB입니다.
  2. USB 반대편 작은 버튼이 BOOTSEL입니다. 피코에 마이크로파이썬을 처음 넣을 때만 누릅니다. 평소 실습에서는 누르지 않습니다.
  3. 보드 한가운데 근처의 아주 작은 초록 불이 온보드 LED입니다. 부품을 꽂지 않고도 켤 수 있습니다.
  4. 양옆의 금속 핀이 다리입니다. 피코 H는 이 다리가 이미 붙어 있어서 브레드보드에 꽂힙니다.

키트 확인

  • 피코 H, 데이터 전송이 되는 USB 케이블, 브레드보드, 점퍼선
  • LED 1개, 저항 1개(220Ω), 버튼 1개, 부저 1개
  • 인체 감지 센서 1개, 센서에 꽂는 암-수 점퍼선 3개
없는 것 색이 여러 개인 네오픽셀, 그로브 쉴드, 와이파이, 가변 저항은 이 키트에 없습니다. 그 부품이 있어야 하는 예제는 넘어갑니다.

확인

우리 키트의 보드는 어느 것입니까?

피코 H는 헤더(핀)가 붙어 있고 와이파이는 없습니다. 칩은 RP2040입니다.

BOOTSEL 버튼은 언제 씁니까?

이미 설치되어 있으면 USB만 꽂습니다. 매번 BOOTSEL을 누르면 저장한 프로그램 쪽이 아니라 설치 드라이브로 열립니다.
