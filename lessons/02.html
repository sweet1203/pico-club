보드를 켜고 말을 걸기

선을 꽂기 전에, 핀 번호 두 종류를 구분하고 Thonny로 보드 위 초록 LED를 켭니다.

핀 번호가 두 개

코드에 쓰는 이름은 GP 번호입니다. 보드를 세고 꽂을 때 쓰는 것은 가장자리 핀 번호입니다. 둘은 다릅니다. GP14는 가장자리 19번 핀입니다.

USB를 위로 두고 왼쪽 위가 1번, 오른쪽 위가 40번입니다.

1 GP0 ··· 17 GP13 부저
40 VBUS 센서 전원 ··· 36 3V3 버튼
18 GND · 19 GP14 LED · 20 GP15 버튼
34 GP28 센서 신호 · 온보드 초록 LED는 GP25 (핀에 안 나옴)
꽂으면 안 되는 곳 핀 40 VBUS와 핀 39 VSYS는 5V입니다. 버튼 선이나 GP 핀에 닿으면 보드가 상합니다. 핀 37은 전원 끄기용이라 부품을 꽂지 않습니다. 3V3과 GND를 선 하나로 바로 잇지 않습니다. 선을 바꿀 때는 USB를 뽑습니다.

브레드보드는 다음 시간부터

가운데 홈을 기준으로 위아래가 끊겨 있습니다. 세로 구멍 다섯 개가 한 줄로 이어집니다. 피코는 그 홈에 걸치듯 꽂습니다. 오늘은 피코만 USB로 연결합니다.

Thonny 연결

  1. Thonny를 엽니다.
  2. 피코 H를 USB로 연결합니다. 충전 전용 케이블이면 컴퓨터가 보드를 못 찾습니다.
  3. 오른쪽 아래에서 인터프리터를 MicroPython (Raspberry Pi Pico) 로 고릅니다. Pico W나 Pico 2가 아닙니다.
  4. 아래 셸에 >>>가 보이면, print('안녕') 을 입력하고 Enter를 누릅니다. 안녕이 한 줄 나오면 연결된 것입니다.
처음이라 드라이브만 보일 때 BOOTSEL을 누른 채 USB를 꽂으면 RPI-RP2 라는 드라이브가 생깁니다. 피코 2는 RP2350으로 보여서 이름이 다릅니다. Thonny의 Install MicroPython에서 보드를 Raspberry Pi Pico로 고르고 설치한 뒤, 케이블을 뽑았다가 그냥 다시 꽂습니다.

실습 · 초록 LED 다섯 번

위쪽 빈 파일에 아래를 직접 입력하고 실행(▶)합니다. 부품은 없습니다. 25는 피코 H 온보드 LED 번호입니다. 와이파이 보드 예제의 Pin("LED") 는 쓰지 않습니다.

onboard_blink.py
from machine import Pin
import time

led = Pin(25, Pin.OUT)

for i in range(5):
    led.on()
    print(i + 1, "번째 켜짐")
    time.sleep(0.4)
    led.off()
    time.sleep(0.4)

print("끝")
  • Pin(25, Pin.OUT) 은 25번을 출력으로 정합니다. 피코가 그 핀의 전기를 켜고 끕니다.
  • on() 은 켜기, off() 는 끄기입니다.
  • time.sleep(0.4) 는 0.4초 기다립니다. 이 줄이 없으면 너무 빨라서 안 깜박인 것처럼 보입니다.
  • 셸에 1번째부터 5번째, 그리고 끝이 찍히면 성공입니다.
실행이 안 끝날 때 다음 시간부터는 while True 때문에 계속 돕니다. 다른 코드를 실행하기 전에 정지(■)를 누릅니다. 저장을 물어보면 오늘은 내 컴퓨터에 저장해도 됩니다.

막히면

  • 포트가 없음 → 케이블을 바꾸고, 인터프리터를 다시 고르고, Thonny를 다시 엽니다.
  • 초록 불이 안 켜지는데 글자는 나옴 → 숫자가 25인지 확인합니다.
  • NameError → 철자와 들여쓰기(칸 맞추기)를 위 코드와 비교합니다. for 안쪽은 띄어쓰기 4칸입니다.

피코 H에서 보드 위 초록 LED를 켜는 핀은?

피코와 피코 H의 온보드 LED는 GP25입니다. GP14는 다음 시간의 바깥 LED입니다.

펌웨어를 설치할 때 고르는 보드는?

피코 H는 와이파이도 없고 피코 2 칩도 아닙니다. 드라이브 이름도 RPI-RP2입니다.
