1차시 · 라즈베리파이 피코 스타터 키트

피코는 어떤 보드일까

오늘은 코드를 쓰지 않습니다. 이름을 구분하고, USB 구멍과 초록 불, BOOTSEL을 찾습니다.

  1. 이름이 여럿인 이유
  2. 입력과 출력
  3. 보드에서 찾기
  4. 키트 확인
01

이름

한 줄라즈베리파이는 화면이 있는 작은 컴퓨터이고, 피코는 불·버튼·센서를 반복해서 다루는 보드입니다. 우리가 산 제품은 라즈베리파이 피코 스타터 키트, 기판 표기는 RASPBERRY PI PICO H(헤더핀 납땜 버전)입니다.
이름무엇인가우리 키트
라즈베리파이 4, 5모니터와 키보드를 꽂는 컴퓨터입니다.아님
피코 H핀이 이미 납땜되어 있습니다. 와이파이는 없습니다. 초록 LED는 GP25입니다.우리 것
피코 W, WH와이파이가 있습니다. 초록 LED를 켜는 코드가 다릅니다.아님
피코 2, 2 W더 새 칩입니다. 참고 자료 여럿이 이 보드를 기준으로 적혀 있습니다.아님

제목에 Pico W, Pico 2, Grove, NeoPixel, Wi-Fi가 있는 예제는 우리 수업 코드가 아닙니다.

02

입출력

입력

바깥 신호를 읽습니다. 버튼이 눌렸는지, 사람이 지나갔는지를 0 또는 1로 받습니다.

출력

핀으로 전기를 내보냅니다. LED를 켜고 부저를 울립니다. 켜짐이 1, 꺼짐이 0입니다.

가운데서 판단하는 말이 마이크로파이썬입니다. 다음 차시에 컴퓨터의 Thonny에서 그 프로그램을 피코로 보냅니다.

03

찾기

  1. USB 구멍이 위

    피코 H는 마이크로 USB입니다. 데이터 케이블로 연결합니다.

  2. BOOTSEL

    USB 반대편 작은 버튼입니다. 마이크로파이썬을 처음 넣을 때만 누릅니다.

  3. 온보드 LED

    보드 위의 아주 작은 초록 불입니다. 부품 없이 켤 수 있고, 핀 번호는 GP25입니다.

  4. 헤더핀

    양옆 금속 다리가 이미 납땜되어 있어서 브레드보드에 꽂힙니다.

키트 안

  • 피코 H, USB 케이블, 브레드보드, 점퍼선
  • LED 1개, 저항 220Ω 1개, 버튼 1개, 부저 1개
  • 인체 감지 센서 1개, 암-수 점퍼선 3개
없는 것. 색이 바뀌는 네오픽셀, 그로브 쉴드, 와이파이, 가변 저항은 이 키트에 없습니다.
