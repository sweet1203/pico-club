핀 약속

정보 수업 실습은 버튼을 뺀 뒤 부저를 GP15에 꽂습니다. 여기서는 버튼과 부저를 같이 쓰므로 부저만 GP13으로 옮겼습니다. LED GP14, 버튼 GP15, 센서 GP28은 정보 수업과 같습니다.

가져오고 버린 것

  • 반응 속도 대결의 생각(무작위 대기, 밀리초, 너무 이른 누름)은 pico-curriculum-36의 5차시에서 왔습니다. 네오픽셀과 그로브 버튼 코드는 우리 LED·풀다운 버튼으로 다시 썼습니다.
  • 반딧불이, 심장 박동, 버튼 벨은 키트 부품만으로 되도록 줄였습니다. 가변 저항, RGB, 음계는 넣지 않았습니다.
  • pico-makers와 36차시 뒤쪽의 대시보드, 구글 시트, 와이파이는 이 키트로 할 수 없어 넣지 않았습니다.
  • 센서의 안정 시간, 유지 시간 다이얼, 종이컵, VBUS 주의는 정보 수업에서 이미 확인한 실습 팁을 그대로 두었습니다.

수업 전에 한번

  1. 케이블이 데이터용인지, Thonny 인터프리터가 Raspberry Pi Pico인지 확인합니다.
  2. 저항 색띠가 220Ω(빨강-빨강-갈색)인지 봅니다.
  3. 인체 감지 센서의 유지 시간 다이얼을 가장 짧게 돌려 둡니다. 안 그러면 8차시 LED가 몇 분씩 안 꺼집니다.
  4. 센서 글자가 VCC · OUT · GND인지, 암-수 점퍼가 키트에 있는지 봅니다.
  5. 부저에 + 표시가 있는지 보고, 7차시에서 소리가 안 나면 선을 바꾸게 안내합니다.

코드는 각 차시 화면에 있고, 같은 내용이 code 폴더의 py 파일에도 있습니다. Thonny에서 그 파일을 열어 실행해도 됩니다.
