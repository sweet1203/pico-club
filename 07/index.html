7차시

버튼 벨

버튼을 누르는 동안 부저가 울리게 합니다. 음계는 다루지 않고, 켜고 끄는 소리만 만듭니다.

  1. 소리의 원리
  2. GP13
  3. 누르는 동안 삑
  4. 세 번만 울리기
01

원리

원리부저도 출력입니다. 핀을 켜면 소리가 나고 끄면 그칩니다. 키트 부저는 이 방식인 경우가 많습니다. 도레미처럼 음 높이를 바꾸려면 다른 종류의 부저가 필요해서, 오늘은 삑만 합니다.
정보 수업에서는 버튼을 뺀 자리에 부저를 꽂기도 합니다. 여기서는 버튼이 GP15를 계속 쓰므로 부저는 GP13, 보드 핀 17입니다.
02

연결

USB를 뽑고 부저만 더합니다. LED와 버튼은 그대로 둡니다.

부저연결
+, 긴 다리, 빨간 선GP13, 핀 17
−, 짧은 다리, 검은 선가까운 GND. 핀 13 또는 핀 23
03

삑

button_bell.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)
buzzer = Pin(13, Pin.OUT)

while True:
    if button.value() == 1:
        buzzer.on()
        led.on()
    else:
        buzzer.off()
        led.off()
    time.sleep(0.05)
  • 소리가 전혀 없으면 +와 −를 바꿔 꽂아 봅니다.
  • 딸깍만 나면 음 높이가 안 바뀌는 부저가 아닐 수 있습니다. 오늘 목표인 눌렀다는 신호로는 쓸 수 있습니다.
04

초인종

누르는 순간 짧게 세 번만 울리고, 손을 뗄 때까지 더 울리지 않습니다.

doorbell.py
from machine import Pin
import time

button = Pin(15, Pin.IN, Pin.PULL_DOWN)
buzzer = Pin(13, Pin.OUT)
before = 0

while True:
    now = button.value()
    if now == 1 and before == 0:
        for _ in range(3):
            buzzer.on()
            time.sleep(0.08)
            buzzer.off()
            time.sleep(0.12)
        while button.value() == 1:
            time.sleep(0.01)
    before = button.value()
    time.sleep(0.05)
