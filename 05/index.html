5차시

누르면 켜지는 불

LED 회로는 그대로 두고 버튼을 더합니다. 누르고 있는 동안에만 불이 켜집니다.

  1. 입력의 원리
  2. 버튼 연결
  3. 누르는 동안 켜기
  4. 누를 때마다 바뀌기
01

원리

원리입력 핀은 바깥 전압을 읽습니다. Pin.PULL_DOWN은 누르지 않았을 때 값을 0으로 붙잡아 둡니다. 버튼을 누르면 GP15와 3.3V가 이어져 값이 1이 됩니다. if는 1일 때만 LED를 켭니다.
02

연결

USB를 뽑고 버튼을 더합니다. 다리는 네 개입니다. 가운데 홈에 걸치고, 대각선으로 마주 보는 두 다리를 씁니다.

부품연결
LED와 저항그대로. GP14, GND 18
버튼 다리 하나GP15, 보드 핀 20
대각선 반대 다리3V3, 보드 핀 36만
3V3만. 핀 39·40(5V)과 핀 37에는 꽂지 않습니다.
03

누르는 동안

button_led.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)

while True:
    if button.value() == 1:
        led.on()
    else:
        led.off()
    time.sleep(0.05)
  • 버튼 핀을 OUT으로 두면 3.3V와 출력이 부딪힐 수 있습니다.
  • 안 눌러도 불이 계속 켜지면 선이 항상 붙어 있는 것입니다. USB를 뽑고 줄을 다시 봅니다.
04

바뀔 때마다

누르는 순간만 잡아 켜짐과 꺼짐을 바꿉니다. 손을 떼기 전에는 한 번만 바뀝니다.

button_toggle.py
from machine import Pin
import time

led = Pin(14, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)
led.off()
before = 0

while True:
    now = button.value()
    if now == 1 and before == 0:
        if led.value() == 1:
            led.off()
        else:
            led.on()
    before = now
    time.sleep(0.05)
